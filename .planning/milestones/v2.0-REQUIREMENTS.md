# Requirements: Vantage — Milestone v2.0 Full Agent Suite & Observability

**Defined:** 2026-07-04
**Core Value:** Given a ticker or investment thesis, produce a fully cited ResearchMemo with explicit Contradictions — in minutes, not the 8-12 hours a junior analyst needs.

## v2.0 Requirements

Requirements for this milestone. Each maps to roadmap phases (starting Phase 5).

### Full Agent Suite

- [x] **AGENT-01**: SentimentNLP agent produces a cited sentiment narrative (news/arXiv sources)
- [x] **AGENT-02**: RiskAssessment agent produces a cited risk narrative
- [x] **AGENT-03**: MacroSector agent produces a cited macro/sector narrative (FRED data)
- [x] **AGENT-04**: ComparableCompanies agent produces a cited comparables narrative
- [x] **AGENT-05**: Orchestrator dispatches all applicable agents in true parallel fan-out (not just 2)
- [x] **AGENT-06**: Synthesis fan-in waits on all dispatched agents before computing memo status

### Execution & Async

- [x] **EXEC-01**: Live per-agent progress panel via WebSocket
- [x] **EXEC-04**: Failed/missing memo sections explicitly marked with reason (not silently omitted)
- [x] **EXEC-05**: Research completes asynchronously (Celery); user can navigate away and return to a completed memo

### ResearchMemo — Contradictions & Polish

- [x] **MEMO-04**: Dedicated Contradictions section (severity-rated agent disagreements)
- [x] **MEMO-05**: COMPLETE / PARTIAL status displayed at a glance
- [x] **MEMO-06**: Total generation cost shown (LLM tokens + external API call counts)

### Follow-Up Chat

- [x] **CHAT-01**: Persistent follow-up chat session grounded on memo text
- [x] **CHAT-02**: Follow-up answers grounded on memo + conversation history only (no RAG re-query)
- [x] **CHAT-03**: Session persists indefinitely and is resumable
- [x] **CHAT-04**: System flags when a follow-up exceeds memo coverage

### Financial Metrics & Anomaly Detection

- [x] **METRIC-01**: Structured financial metrics stored per (ticker, metric_name, period)
- [x] **METRIC-02**: Anomalies appear as named, severity-rated items in the fundamentals section
- [x] **METRIC-03**: Anomaly detection uses the company's own historical range (isolation forest)

### Watchlist & Alerts

- [x] **WATCH-01**: User can add/remove a ticker from a personal watchlist
- [x] **WATCH-02**: User can view all watchlist tickers with latest status
- [x] **WATCH-03**: User can create a NEW_FILING alert rule for a watchlisted ticker
- [x] **WATCH-04**: User can create a PRICE_MOVE alert rule with a percentage threshold
- [x] **WATCH-05**: User can create a SCHEDULED alert rule (recurring re-research)
- [x] **WATCH-06**: User receives an in-app notification when an alert rule triggers
- [x] **WATCH-07**: User can view alert history for a watchlisted ticker
- [x] **WATCH-08**: User can enable/disable an alert rule without deleting it
- [x] **WATCH-09**: Alert rule evaluation runs as a scheduled Celery beat job

### Observability & Cost

- [x] **OBS-01**: LangSmith traces for every agent call
- [x] **OBS-02**: Per-agent cost breakdown aggregated to per-memo total
- [x] **OBS-03**: Offline RAGAS evaluation Celery beat job

## v3 Requirements

Deferred beyond this milestone. Tracked but not in current roadmap.

### Alerts — Advanced

- **SENTIMENT_SPIKE**: Alert rule requiring continuous FinBERT inference on a live news stream

### Cross-Memo Analytics

- **XMEMO-01**: Cross-memo Anomaly/Risk queries (requires promoting Anomaly/Risk to first-class entities)

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| SENTIMENT_SPIKE alert rule | Requires continuous FinBERT inference on live news stream (deferred) |
| Cross-memo Anomaly/Risk queries | Requires promoting Anomaly/Risk to first-class entity (deferred) |
| Admin roles / multi-role authorization | Single user role at launch |
| Email/push notifications for alerts | In-app pub/sub only at launch |
| Social or sharing features | Memos are private |
| Real-time market data streaming | yfinance polling only |
| Mobile native app | Web frontend only |
| Fine-tuning FinBERT | Uses pre-trained model at launch |
